# PRTS 终端功能说明

本主题把功能分成三层：Ly 原生界面、Lua 视觉层和外部维护工具。

| 功能 | 实现位置 | 是否是真实状态 |
| --- | --- | --- |
| 用户名、密码、会话选择 | Ly 原生 | 是 |
| 时间、TTY、版本 | Ly `corner_*` | 是 |
| PRTS 标签 | Ly `custom_labels` | 是配置值 |
| PRTS 启动序列、扫描点、徽记组装 | Lua 动画 | 视觉状态 |
| F8 诊断通道 | Ly `custom_commands` | 命令反馈 |
| KMSCON 字体切换 | `tools/kmscon.sh` | 系统状态 |

当前配置启用了右上角时间与 TTY、左下角 Ly 版本、右下角 PRTS 标签，以及 F8
诊断命令。F1/F2/F5/F6/F7 保持 Ly 默认的关机、重启、亮度和密码显示功能。

“PRIESTESS LINK // MEMORY AWAKENED”是主题的启动文案，不代表程序已经读取了
Priestess、认证或用户系统中的任何真实数据。
## 安全使用

预览配置会清除启动脚本、保存目录、电源快捷键和自动登录设置。安装脚本会先构建、
校验、模拟执行动画，然后备份目标目录，再复制可被 Ly 普通用户穿越的文件。
